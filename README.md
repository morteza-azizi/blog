# Morteza Azizi

Personal site and technical blog: [mortezaazizi.com](https://www.mortezaazizi.com/)

Writing about software architecture, distributed systems, .NET, and Azure — including the **Architecture Through Engineering** series.

## Content

| Path | Role |
|---|---|
| `content/posts/` | Articles |
| `content/series/` | Series pages (title + description) |
| `content/about/` | About page |

`tags` are technical topics. `series` is a body of related articles.

```yaml
series:
  - Architecture Through Engineering

tags:
  - azure
  - messaging
```

A post with no `series` still renders normally. Optional `description` is used as the listing summary; otherwise Hugo takes the first real sentence.
